# Template de artigo MDX

> **Resumo/introdução do artigo:** escreva aqui uma frase curta que apresente o assunto e desperte o interesse do leitor.

---

<b>
  DD Mmm AAAA
</b>

<br/>

<span>
  X min. de leitura
</span>

## Título da primeira seção

Comece apresentando o assunto principal do artigo. Explique o contexto e introduza os conceitos necessários para que o leitor consiga acompanhar o restante do conteúdo.

Você pode utilizar **negrito**, *itálico*, ***negrito + itálico*** e ~~texto riscado~~ quando necessário.

Também é possível adicionar [links externos](https://exemplo.com/) para complementar alguma informação.

### Subseção

Use subseções quando precisar dividir uma seção maior em assuntos específicos.

Você pode destacar uma informação importante com **negrito** ou utilizar **outra forma de destaque**.

> Use este formato para uma citação, observação ou informação que mereça destaque.

### Outra subseção

Caso precise explicar um processo, conceito ou exemplo, desenvolva o conteúdo aqui.

Você também pode utilizar uma lista:

* **Item 1** — descrição ou explicação.
* **Item 2** — descrição ou explicação.
* **Item 3** — descrição ou explicação.

Ou uma lista numerada:

1. Primeiro passo.
2. Segundo passo.
3. Terceiro passo.

## Comparação ou explicação visual

Quando precisar apresentar duas ou mais imagens lado a lado, você pode utilizar HTML/JSX:

<div align="center">

<img src="../img/posts/categoria/imagem-1.webp" className="bg-transparent" />

<img src="../img/posts/categoria/imagem-2.webp" className="bg-transparent" />

</div>

## Código

Quando o artigo precisar apresentar código, utilize um bloco cercado por três crases e informe a linguagem:

```javascript
const exemplo = "Olá, mundo!";

console.log(exemplo);
```

Para comandos de terminal:

```bash
npm install exemplo
```
